# Fundamentals of C++ Programming - Solutions & Exercises

This repository contains my C++ solutions, code examples, and practice exercises written while studying the textbook "Fundamentals of C++ Programming" by *Richard L. Halterman*.

## 📌 Contents & Topics Covered
- Basics & Control Flow: Variables, Conditionals (if, switch), and Loops (for, while).
- Functions & Logic: Custom functions, overloaded functions, and mathematical algorithms.
- Pointers & Memory Management: Low-level memory mechanics, pointers, and memory handling in C++.
- Data Structures & Problem Solving: Arrays, strings, and console-based applications.

- Language: C++
- IDE / Editor: Visual Studio Code / C++ Compiler
- Version Control: Git & GitHub Desktop
